# TecnoStock

Sistema de control e historial de inventario desarrollado en PHP y MySQL.

## 🛠️ Tecnologías utilizadas
- PHP
- MySQL / MariaDB
- Bootstrap (CSS)

## 🚀 Instalación y uso
1. Clonar el repositorio o descargar el proyecto.
2. Colocar la carpeta dentro de `xampp/htdocs/`.
3. Importar la base de datos MySQL.
4. Abrir en el navegador: `http://localhost/tecnostock`
